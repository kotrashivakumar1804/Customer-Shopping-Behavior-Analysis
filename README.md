# Customer Shopping Behavior Analysis 📊

## 🔍 Project Overview
This project analyzes customer shopping behavior using transactional retail data.
The goal is to identify spending patterns, customer segments, and product performance
to support data-driven business decisions.

An interactive **Power BI dashboard** is built to visualize key insights.


## 🗂 Dataset Summary
- Rows: 3,900
- Columns: 18
- Data includes:
  - Customer demographics (Age, Gender, Location)
  - Purchase details (Category, Amount, Item)
  - Subscription status
  - Discounts, shipping type, and review ratings


## 🛠 Tools & Technologies
- **Python** (Pandas, NumPy)
- **PostgreSQL**
- **SQL**
- **Power BI**
- **Jupyter Notebook**


## 📊 Analysis Performed

### 🔹 Python (EDA & Data Cleaning)
- Handled missing values in review ratings
- Feature engineering (age groups, purchase frequency)
- Data consistency checks
- Exported clean data to PostgreSQL

### 🔹 SQL (Business Analysis)
- Revenue by gender
- High-spending discount users
- Top products by rating
- Subscribers vs non-subscribers analysis
- Customer segmentation (New, Returning, Loyal)
- Revenue contribution by age group

### 🔹 Power BI Dashboard
- KPIs: total customers, average purchase amount, average rating
- Revenue & sales by category
- Subscription analysis
- Age group insights
- Interactive slicers (gender, category, shipping type)


## 📈 Key Insights
- Footwear generates the highest revenue
- Middle-aged customers contribute the most revenue
- Subscribers generate higher repeat purchases
- Discounted products still drive strong sales


## 📌 Business Recommendations
- Promote subscription benefits
- Target high-revenue age groups
- Optimize discount strategies
- Focus marketing on top-rated products
